VTX-0.1 — Minimum Viable Video-Text (BUILD Package)

Source-grounded reference implementation, single-root A/B animation pair, deterministic trace validator, offline HTML5 Canvas workbench + blinded perceptual test harness, and retained revision history for Watson Hartsoe’s Flour Test / The Burning of the Abominable House research (SCION v1.1).

Scope & Provenance Note - Invented Adaptation: vtx01_case_a_assist and vtx01_case_b_deliberate are an invented minimal two-actor parlor test, not a recovered scene from Italo Calvino’s 1973 text. - Synthetic Policies (P1–P4): cases/policies_synthetic_p1_p4.json defines explicitly invented demonstration clauses separating World State from Corroborated Visual Evidence (authored goal never counts as visual corroboration). - Human Perceptual Gate (PENDING): The blinded zero-caption evaluation harness (viewer/index.html) and unlabeled .mp4 exports are ready, but voluntary human respondent testing and narrative-interest judgment have not been conducted (UNTESTED).

Reproduction Instructions#

Tested on macOS (arm64) with: - Node.js /opt/homebrew/bin/node (v23.6.0) - Python /Users/gaia/anaconda3/bin/python3 (3.11, numpy 1.26.4, opencv-python 4.10.0) - FFmpeg /Users/gaia/anaconda3/bin/ffmpeg (4.3.2, libx264)

1. Derive Case B from Case A + Patch and Run Gate Validation#

bash
/opt/homebrew/bin/node "/Users/gaia/burning house/vtx01_build/src/validate_vtx.js"

This deterministically regenerates cases/case_b_deliberate.vtx.json from cases/case_a_assist.vtx.json + cases/patch_a_to_b_goal.json, verifies identical exogenous E1 frames (0..76), inspects all 384 frames per case (including all 73 frames of the carried Wedge_1 interval [10.50, 13.50] s and the 9.50 s camera cut), and writes revisions/validation_report.json + revisions/traces_a_and_b.json.

2. Rebuild Offline Viewer Bundle#

bash
/opt/homebrew/bin/node "/Users/gaia/burning house/vtx01_build/src/build_viewer_bundle.js"

Open /Users/gaia/burning house/vtx01_build/viewer/index.html directly in any modern browser (file:// compatible, zero server required): - Tab 1 — Blinded Perceptual Test (Zero Captions): Randomizes Case A and Case B as unlabeled Clip X / Clip Y with zero captions, state Inspector, or trace spoilers, collects independent viewer judgments + confidence + timestamp cues, and exports a JSON response packet before unblinding. - Tab 2 — Synchronized A/B Inspector: Frame-accurate 24 fps scrubber (0..383), live Chance / Memory / Consequence traces, and side-by-side synthetic policy (P1–P4) World vs. Corroborated Evidence tables. - Tab 3 — Live VTX-0.1 Remix Editor: Edit E2_root_action.goal, Jolt_1 impulse, or Sack_B initial memory live in JSON, replay causal traces, and inspect immediate visual changes on canvas.

3. Re-render 1280x720 Unlabeled .mp4 Videos & Frame Contact Sheets#

bash
/Users/gaia/anaconda3/bin/python3 "/Users/gaia/burning house/vtx01_build/src/export_mp4.py" rev2_accepted
